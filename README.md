Calculadora de IMC
Sobre o projeto

Este projeto consiste em uma Calculadora de IMC (Índice de Massa Corporal), desenvolvida como parte de um laboratório prático de desenvolvimento de aplicações com Inteligência Artificial.

O objetivo é permitir que o usuário informe seu peso e sua altura para obter o resultado do cálculo do IMC.

Tecnologias utilizadas
HTML: estrutura da aplicação.
CSS: aparência e organização visual.
JavaScript: realização dos cálculos.
Google Gemini: geração inicial do código.
Gemini Code Assist: auxílio na explicação e documentação do código.
Visual Studio Code: edição do projeto.
GitHub Desktop: controle de versões.
GitHub Pages: publicação do aplicativo.
Como utilizar
Acesse o aplicativo pelo link abaixo.
Informe seu peso em quilogramas.
Informe sua altura em metros.
Clique no botão de calcular.
Confira o resultado apresentado.
Fórmula do IMC

IMC = Peso / (Altura × Altura)

Exemplo:

Peso: 70 kg
Altura: 1,75 m

Resultado: 22,86
